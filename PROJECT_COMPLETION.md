## 🎨 Design Specifications

### Typography
- **Display Sizes**: 28px-32px (Headlines)
- **Body Sizes**: 12px-16px (Content)
- **Weights**: 400-800 (Regular to ExtraBold)
- **Font**: Modern sans-serif (Material Design 3)
- **Spacing**: -0.5 letter-spacing on headlines

### Spacing System (4px Grid)
- Tight: 4px, 8px
- Medium: 12px, 16px, 20px
- Large: 24px, 28px, 32px

### Rounded Corners
- Standard: 20px (cards, buttons, containers)
- Tight: 16px (input fields, badges)
- Loose: 24px (large surfaces)

### Shadow Effects
- **Standard Card**: 0, 4px, 12px blur, 6% opacity
- **Hover Elevated**: 0, 12px, 20px blur, 10% opacity
- **Soft**: 0, 2px, 4px blur, 4% opacity

### Animations (300ms Standard)
- Card tap: Scale 0.95
- Favorite heart: Scale 1.2 + color fill
- Search focus: Border glow + color change
- Nav label: Slide-in animation
- Carousel: Smooth page scroll
